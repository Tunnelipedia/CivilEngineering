Method & Terminology Notes

Interface conditionPhysical meaningEffect on forces
No-slipShear stress fully mobilised at lining–ground interfaceM same as full-slip; N varies more (larger Nd amplitude)
Full-slipZero interface shear (frictionless, St=0)M same as no-slip; N varies less (smaller Nd amplitude)
Bending moment is identical for both interface conditions — verified against textbook Fig. 6.8 (both M curves overlap). Radial compatibility at the interface is the same regardless of slip condition; ovalisation deformation is identical. The interface condition only changes how much shear stress transfers into hoop force, giving a larger Nd amplitude for no-slip and smaller for full-slip.

Wet and dry cases give genuinely different M and N because buoyancy reduces effective unit weight, lowering the deviatoric stress P₀ = σ′v−σ′h. Dry has higher P₀ → higher M and larger N variation. Water pressure itself adds only uniform hoop thrust Nw — it contributes zero moment.
Radial ovalisation displacement uses thin-ring theory: u = M·r₀²/(2·El·Ieff)·cos2θ. Since M is identical for both interface conditions, the displacement shape is also identical — only the amplitude differs with wet vs dry loading.

Values Around the Ring (every 30°)

Method note: θ is measured counter-clockwise from the right springline (θ = 0°); crown = 90°, left springline = 180°, invert = 270°. Formulas (Curtis-Muir Wood, verified against textbook Worked Example 6.3):
Q₃ = Eg·r₀³·(1−νl²) / [12·El·Ieff·(1+νg)] · flexibility ratio
Q₁ = Eg·r₀·(1−νl²) / [El·t·(1+νg)] · compressibility ratio
ω = (3−2ν)/(3−4ν);   P₀ = σ′v−σ′h (full deviatoric);   Pu = (σ′v+σ′h)/2
Sn = P₀/2·(1−Q₃)/[(1+Q₃)·ω];   St = P₀/2·(1+2Q₃)/[(1+Q₃)·ω]
M = r₀²/6·(2Sn+St)·cos2θ   [identical for both interface conditions]
Nd,ns = −r₀/3·(Sn+2St)·cos2θ (No-slip);   Nd,fs = −r₀/3·Sn·cos2θ (Full-slip, St=0)
Nu = Pu·r₀/(1+Q₁) (both cases);   Nw = Pw·r₀ added to wet case only
All stresses evaluated separately for wet (buoyancy-adjusted σ′v) and dry (full bulk σ′v). This elastic-continuum closed form assumes a deep tunnel (uniform far-field stress across the ring), a "wished-in-place" lining, and a homogeneous, isotropic, linear-elastic ground and lining — it does not capture staged construction, ground non-linearity, layered strata, or explicit radial-joint articulation (only the smeared stiffness-ratio approximation above). Use it as a preliminary/cross-check tool, not a substitute for a validated bedded-beam-spring or FE model for final design.
